# 사이트 설계도(PRD) — (미정: 내 브랜드 스킨케어 선물 사이트)

작성일: 2026-10-25 · 이 문서는 사이트를 고칠 때마다 다시 보는 기준이다.

## 1. 한 줄 정의
선물하기 좋은 내 브랜드 스킨케어를 소개하고, 스토어 구매로 이어 주는 사이트.

## 2. 손님
- 누가: 화장품 선물을 고르는 사람 (가족·친구·연인·동료에게 줄 선물)
- 어디서 알고 오나: 인스타그램, 네이버 검색·블로그, 지인 소개

## 3. 손님이 궁금한 것 (연락하기 전에)
1. 선물 포장이 되는지, 메시지 카드를 넣을 수 있는지
2. 가격대와 세트 구성 (예산에 맞는 세트가 있는지, 무엇이 들었는지)
3. 받는 사람 피부를 모르는데 누구에게나 써도 되는지 (성분, 피부 타입)
4. 언제 도착하는지 (생일·기념일 전에 받을 수 있는지)

## 4. 믿게 할 증거 (실제로 있는 것만)
- 제품·포장 실제 사진 (있음)
- 전성분표·시험 자료: (준비 중)
- 후기: (실제 후기가 생기면 넣는다. 지금은 자리만)

## 5. 누르게 할 버튼 하나
- 버튼 이름: 스토어에서 구매하기
- 누르면: 스토어 상품 페이지로 이동해서 결제 (스토어 링크: 미정)
- 보조 버튼: 선물 문의하기 → 문의 폼 (단체 선물·수량 문의)

## 6. 페이지 구성 (위에서 아래로)
한 장짜리 페이지.
1. 첫 화면 — 한 문장 + "스토어에서 구매하기" 버튼
2. 선물 세트 소개 — 제품·포장 사진, 세트 구성, 가격 (미정)
3. 선물 손님이 궁금한 것 — 포장·카드 / 누구 피부에나 맞는지 / 도착 기간
4. 후기 자리 (비워 둠)
5. 문의 폼 — 단체 선물·수량 문의
6. 맨 아래 — 연락 방법, 사업자 정보 (미정)

## 7. 문의 폼에서 받을 것
- 이름, 연락처
- 수량·예산 (몇 개를, 얼마 예산으로)
- 개인정보 수집·이용 동의 (필수)

## 8. 정확해야 하는 사실 (사용자가 말한 그대로)
- 브랜드(사이트) 이름: (미정)
- 가격: 세트별 가격 (미정)
- 시간: 배송 기간 (미정)
- 위치: 온라인 판매 — 스토어 링크 (미정)
- 선물 포장·메시지 카드 가능 여부: (미정)
- 연락 방법: (미정)
- 사업자 정보: (미정)

## 9. 이번에 넣지 않을 것
- 사이트 안 결제·장바구니 (결제는 스토어에서 한다)
- 회원가입·로그인 (따로 원하지 않아 기본으로 뺐다)
- 문의 알림 메일
- 손님이 사진 올리기
- 상품별 상세 페이지 여러 장 (이번엔 한 장)

## 10. 첫 화면 한 문장 후보
1. 마음을 전하는 스킨케어 선물, [브랜드 이름]
2. 고마운 사람에게 건네는 스킨케어 한 세트
3. 특별한 날을 위한 스킨케어 선물

## 11. 다음에 할 것
- 8번의 (미정) 칸 채우기: 브랜드 이름, 스토어 링크, 세트 가격, 배송 기간, 포장·카드 가능 여부, 연락 방법, 사업자 정보
- 전성분표 준비해서 "누구 피부에나 맞는지" 칸에 넣기
- 실제 구매 후기가 모이면 후기 자리 채우기
- 필요해지면 사이트 안 결제, 회원가입 검토

## 12. 만드는 방법 (클로드가 끝까지 만들 때 기준)
- 분위기: 고급스러운 · 참고 디자인: 없음 — 클로드가 정함
- 디자인 기준: frontend-design 스킬
- 문의 저장: 예 → Supabase(leaderpl-admin 스킬) + /admin
- 회원가입: 이번엔 아니요
- 배포: GitHub 공개 저장소 + Vercel

## 13. 만드는 순서 (클로드가 처음부터 끝까지 한 번에)
1. 스타일(색·글꼴)을 분위기에 맞게 정하고 첫 화면부터 만든다
2. GitHub 공개 저장소에 올리고 Vercel로 배포해 내 주소를 만든다
3. 선물 문의 폼 → Supabase 저장 → /admin 관리자 페이지까지 만든다
4. 다 만든 뒤 한 번에 보고: 내 사이트 주소 · 관리자 주소 · 확인 방법 · 사용자가 할 일
- 사용자가 직접 할 일(이때만 멈춤): 로그인, 결제, 관리자 비밀번호(ADMIN_PASSWORD) 입력
